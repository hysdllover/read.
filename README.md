# 국어 학습 대시보드

수능 국어 전용. 홈 · 모의고사 · 제재별 · 노트 4개 탭 + 설정(우상단 톱니).
아이패드 가로에서는 2단 화면, 글자 크기·굵기·글꼴은 설정 → 화면에서 기기별로 조절 (기본: 작고 얇게, 내 글꼴 파일·구글 폰트 이름도 사용 가능).
아이폰/아이패드 Safari에 맞춰 제작, 입력 즉시 자동 저장.

## 올리는 법 (GitHub Pages)

1. 새 저장소 생성 (예: `korean-dash`, Public)
2. 아래 파일을 **폴더 없이 그대로** 업로드
   `index.html` `style.css` `core.js` `ui.js` `sync.js` `view-home.js` `view-reading.js` `view-exam.js` `view-genre.js` `view-settings.js` `view-report.js` `widget.js` `widget-preview.js`
   `sw.js` `manifest.json` `icon-180.png` `icon-192.png` `icon-512.png`
   (`build-preview.js`, `preview.html`은 확인용이라 올리지 않아도 됩니다)
3. Settings → Pages → Source: `Deploy from a branch` → `main` / `/(root)` → Save
4. 1~2분 뒤 `https://아이디.github.io/korean-dash/` 접속
5. Safari 공유 → **홈 화면에 추가** (앱처럼 전체화면으로 열림)

## 열기

- 코드 선택 없이 바로 열립니다. (예전 0~9 코드로 쓰던 기록은 마지막에 쓰던 칸을 그대로 이어서 사용)

## 기기 연동 (아이폰 ↔ 아이패드)

1. GitHub → Settings → Developer settings → Personal access tokens → **Tokens (classic)** → Generate new token
2. 권한은 **gist** 하나만 체크하고 생성 → 토큰 복사 (한 번만 보이니 메모)
3. 앱 → 설정 → 기기 연동 → 깃허브로 연결 → 토큰 붙여넣기
4. 아이패드에서도 **같은 토큰**을 넣으면 같은 비공개 Gist와 기록을 자동으로 찾아 연결됩니다

- 저장할 때마다 4초 뒤 자동 업로드, 앱을 다시 열 때 자동 다운로드
- 두 기기에서 따로 쓴 경우 **항목 단위로 병합**됩니다 (같은 항목은 나중에 고친 쪽이 남고, 삭제도 반영)
- 토큰은 그 기기에만 저장되고 깃허브 외 다른 곳으로 나가지 않습니다

## 저장·백업

- 모든 입력은 저장 즉시 브라우저(localStorage)에 기록됨
- 하루 1회 자동 저장본 생성, 최근 7일 보관 → 설정 탭에서 날짜 탭하면 복원
- 설정 → **백업 파일 내려받기** 로 JSON 저장, 다른 기기에서 **불러오기**

## 홈 화면 앱 · 오프라인

- 홈 화면 아이콘(`icon-*.png`)과 `manifest.json`으로 앱처럼 열림
- `sw.js`: 온라인이면 항상 최신 파일로 열고, **인터넷이 없을 때는 저장본으로 열림**. 새 버전이 올라오면 앱이 자동으로 한 번 새로고침
- 파일을 고쳐 올릴 때는 `sw.js`의 `CACHE`와 `core.js`의 `APP_VER`를 같은 새 값으로 올려 주세요 (현재 `kor-v18`, 설정 맨 아래에 표시)

## 홈 화면 위젯

- iOS는 Safari 웹앱 위젯을 지원하지 않아 무료 앱 **Scriptable**로 만듭니다 → `widget.js` (스크립트 하나로 여러 위젯)
- 앱 설정 → 홈 화면 위젯에서 위젯을 여러 개 만들고(이름·복제·삭제) 미리보며 구성
  - 종류: 추이 그래프 · 큰 숫자 · 요약 · 목표 달성 · 최근 기록 · 영역별 오답 · 약점 제재 · 행동강령
  - 지표 · 기록 수 · 그래프 모양(곡선·직선·막대·점) · 표시 항목 · 디자인 6종 · 정렬
  - 한글 글꼴 6종 · 숫자 글꼴 10종 · 숫자 굵기 · 글자 크기
  - **직접 구성**: 제목·큰 숫자·그래프·숫자 줄·목표 고리·최근 기록·영역별 오답·약점 제재·행동강령·문구·구분선·여백을 골라 순서대로 쌓고 각각 옵션 지정
  - **직접 디자인**: 배경·글자·강조·달성·미달·포인트 색, 그라데이션 배경, 여백
- 구성은 `settings.widgets`에 저장되어 기기 연동으로 위젯에 반영 → 위젯 **Parameter**에는 위젯 이름만 적기
- 크기: 홈 화면 작게·중간·크게, 잠금 화면 원형·사각·한 줄 (`widget-preview.js`가 미리보기·편집기)

## 기능을 고치거나 추가할 때

기록은 `localStorage`에 들어 있고 화면 코드와 분리되어 있어, **파일을 덮어써도 기록은 유지**됩니다.

- 화면 하나만 고치기 → 해당 `view-*.js` 파일만 교체
- 탭 추가 → `view-새이름.js` 파일 1개 만들고 `index.html`에 `<script src="view-새이름.js"></script>` 한 줄 추가
  ```js
  App.register({ id:'newtab', label:'탭이름', title:'화면 제목', icon:'○',
    render: function(root){ /* root에 내용 붙이기 */ },
    add: function(){ /* 우상단 ＋ 눌렀을 때, 없으면 생략 */ } });
  ```
- 저장 항목(필드) 추가 → `core.js`의 `DEFAULTS()`에만 추가. 기존 기록은 `migrate()`가 그대로 유지함
- 색상/글자 크기 → `style.css` 맨 위 `:root` 블록만 수정 (이 블록은 지우지 말 것)

## 기록 구조

| 저장소 | 내용 |
|---|---|
| `reading` | 독해 노트 (구분·제목·내용·상단고정) |
| `exams` | 시행일, 출제(평가원/교육청/사설/기타), 시험명, 선택과목, 원점수·표준점수·백분위·등급, 독서/문학/선택 오답 수, 소요 시간, 메모·총평, 행동강령 |
| `passages` | 영역(독서·문학), 제재(인문/철학/사회/경제/과학/기술 · 고전산문/현대산문/고전시가/현대시), 지문명, 출처, 문항수·오답수, 체감 난이도, 오답 원인, 오답 정리, 풀이 방법론 정리 |

## 인쇄 (A4)

- 설정 → 인쇄 → **A4 리포트 보기**(또는 모의고사 탭 맨 아래) → 인쇄
- 요약 · 목표 대비 · 원점수/백분위 추이 · 모의고사 표 · 제재별 표 · 오답 원인이 A4에 맞춰 출력됩니다
- 인쇄 버튼이 안 먹으면 Safari 공유 → 프린트
